# OrangeStorm Giga native dependency contract

This document describes the native dependencies used by 4.2.0 and retained by the 4.2.1-rc1 module from the audited Elegoo configuration. It is a comparison checklist, not an instruction to replace printer.cfg. The [exact native excerpts](ORANGESTORM-GIGA-EXCERPTS.txt) retain the original macro bytes, including their French runtime messages and comments. Their wrapper text is English. Excerpts omit private calibration and are not an include file.

**REQUIRED EXACTLY** means the code directly names an object, variable, state or value. **REQUIRED SEMANTICALLY** means the behavior is required but does not prove that every whitespace character or unrelated command is necessary. **REFERENCE ONLY** records the tested implementation without claiming that it is a hardcoded module requirement. A row can separate an exact interface from its semantic implementation.

| Dependency | Classification | Required contract and source evidence |
|---|---|---|
| Public PAUSE | REQUIRED EXACTLY (name); REQUIRED SEMANTICALLY (body) | GapGuard._execute_pause invokes PAUSE once. It must save the print state, park, set native flags and stop the current file with M25. The reference does not call BASE_PAUSE. Native must report paused and inactive before the post-pause hook. Live printer.cfg:502. |
| Public RESUME | REQUIRED EXACTLY (macro object and variables); REQUIRED SEMANTICALLY (manual behavior) | AutoRecovery.bind looks up gcode_macro RESUME. Manual RESUME remains native, with its E100 F200 purge. AutoRecovery never calls it; it uses the saved state and sends M24 directly. Live :379. |
| Public CANCEL_PRINT | REQUIRED SEMANTICALLY | The user's existing cancel closes/resets the file, clears PLR state and stops heating. GapGuard observes lifecycle changes; it does not implement or invoke a custom cancel. Live :456. |
| RESUME.saved_x/y/z/e | REQUIRED EXACTLY | pause_completed captures these keys; guard detects changes. PAUSE must populate them for the interrupted print. Finalization restores saved_e and the saved G-code states. |
| RESUME.etemp | REQUIRED EXACTLY | Saved hotend target used for reheating; finite, positive and within heater limits. GapGuard preserves the pre-pause target even when the native macro's temperature-dependent save would skip it. |
| RESUME.bed_temp, bed_temp1, bed_temp2, bed_temp3 | REQUIRED SEMANTICALLY for native manual resume | Native PAUSE saves four targets and RESUME restores them. AutoRecovery does not change or restore bed targets. These names belong to the unchanged native macro interface, not a direct AutoRecovery lookup. |
| PAUSE/RESUME.flag_print_status | REQUIRED EXACTLY | AutoRecovery.guard checks PAUSE=0/RESUME=1 while paused, then PAUSE=1/RESUME=0 after finalization. Start/end/cancel must establish the appropriate state. |
| timelapse_state_a and timelapse_state_b | REQUIRED EXACTLY | gcode_move.saved_states entries are captured and checked for changes. AutoRecovery restores B with MOVE=1/MOVE_SPEED=250, then A with MOVE=1/MOVE_SPEED=50. PAUSE creates A before retract/lift and B afterward. |
| PAUSE and CANCEL_PRINT flag_home_x/flag_home_y | REQUIRED SEMANTICALLY | Native macros use these flags to permit movement. Their names are required by those unchanged macros. They must accurately track homing and motor-disable state; GapGuard does not manage them. |
| homing_override | REFERENCE ONLY (exact motion sequence); REQUIRED SEMANTICALLY (flag updates) | The reference sets homing flags in its G28 branches. AutoRecovery does not invoke or look up homing_override. Its machine-specific coordinates are not an installation overlay. Live :605. |
| M84 | REQUIRED SEMANTICALLY for native flag lifecycle | Reference disables steppers and clears PAUSE/CANCEL homing flags. The exact SET_KINEMATIC_POSITION geometry is reference-only. GapGuard does not call M84 directly. Live :656. |
| output_pin fan1 | REQUIRED EXACTLY (object name/type interface); REQUIRED SEMANTICALLY (scale conversion) | Module uses get_status()['value'], scale, and SET_PIN PIN=fan1. Runtime value is normalized 0..1. Scale 255 is the tested native M106/M107 convention; the Python conversion accepts any finite positive scale but other integrations are not validated. znp_thr1.cfg:17. |
| heater_bed, heater_bed1, heater_bed2, heater_bed3 | REQUIRED EXACTLY for unchanged native macros | First is heater_bed; the remaining three are heater_generic objects. Native PAUSE/RESUME read/write these exact names. GapGuard's own cooldown and idle branch only write the extruder. Do not copy heater pins or PID data from another machine. |
| pause_resume | REQUIRED EXACTLY (object/attributes) | AutoRecovery reads is_paused, sd_paused and pause_command_sent; all must remain false for the native M25 pause ownership used here. A BASE_PAUSE-owned pause is rejected. recover_velocity=50 is reference-only for this direct-M24 recovery path. Live :376. |
| virtual_sdcard | REQUIRED EXACTLY (object/API); REQUIRED SEMANTICALLY (file lifecycle) | Module needs is_active(), file_path(), native M24/M25 and reset_file events. Monitoring requires an active file with a nonempty current path. Local G-code directory is not a universal requirement. Live :329. |
| print_stats | REQUIRED EXACTLY | Its state participates in print, pause, complete, cancelled and error decisions. RESUME being sent alone never proves actual printing. |
| gcode_move / toolhead / extruder / buttons | REQUIRED EXACTLY (API contracts) | Saved states, parser/position state, physical completion, timestamped extruder history, heater and grouped button callbacks are used by the module. The configured extruder name must resolve. |
| save_variables | REQUIRED SEMANTICALLY for native macros | Existing macros persist was_interrupted, last_file and filepath. Its storage path is installation-specific; no private saved_variables file is distributed. plr.cfg:62. |
| clear_last_file | REQUIRED SEMANTICALLY for native end/cancel | Native calls must resolve to a macro that clears last_file/filepath as expected. Not called directly by GapGuard. plr.cfg:36. |
| clear_plr | REQUIRED SEMANTICALLY for native end/cancel | RUN_SHELL_COMMAND CMD=clear_plr must remain functional. The exact local shell path is reference-only; do not execute it as an installation test. plr.cfg:18. |
| PRINT_START / PRINT_END | REQUIRED SEMANTICALLY for native state lifecycle | Initialize/reset macro flags and persistent interrupted-file state. Their unrelated moves, mesh loading and velocity settings remain machine-specific. Live :332/:347. |
| respond | REQUIRED SEMANTICALLY for native RESPOND calls | The existing object provides messages used by the macros. plr.cfg:11. |
| idle_timeout GapGuard branch | REQUIRED SEMANTICALLY | While pause_origin is gapguard, set only the nozzle target to zero. This prevents the default TURN_OFF_HEATERS path from dropping the four bed targets. Use the matching overlay, preserving the other native branches. Live :583. |

## Reading the exact excerpts

Each excerpt gives its original filename, starting line and SHA-256. The checksum covers the captured block bytes, including comments. It is provenance, not a requirement to replace a functionally equivalent block. The whole live printer.cfg hash is recorded in [configuration](CONFIGURATION.md); the complete private file is not distributed.

The module evidence is in [gapguard.py](../src/gapguard.py): AutoRecovery.bind/pause_completed/guard/finalize, GapGuard._ready/_execute_pause/_cool_sfs_pause, the fan methods, and Machine.observe. Macro evidence is in the accompanying exact excerpts. No additional dependency or safety condition is introduced by this document.
